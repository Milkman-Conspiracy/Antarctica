Server overview

This server aims to provide a near-vanilla Minecraft: Java Edition experience. The server runs on Paper.

Software: :contentReference[oaicite:4]{index=4}

Client Requirements

Connect using the official client: :contentReference[oaicite:5]{index=5} / :contentReference[oaicite:6]{index=6} Minecraft: Java Edition. Recommended version: 1.21.11.

  • Forbidden: modified clients that provide unfair gameplay advantages (combat automation, x-ray, aim-assist).
  • Allowed: cosmetic or QoL mods that do not alter gameplay balance.
  • Server-side anti-cheat is active to help ensure fair play.

Gameplay philosophy

  • Vanilla survival gameplay
  • Fair multiplayer experience
  • Minimal admin interference

Plugins are used for administration, moderation and technical features.

Administration & moderation

  • Block logging and rollback tools
  • Anti-cheat monitoring
  • Permission management

Administrative intervention is minimal but will occur when required to address griefing, cheating or serious rule violations.

Bug reports & suggestions

Players are encouraged to report server bugs, plugin errors and performance issues. Constructive suggestions are welcome; use the in-game report form or community channels (Discord / issue tracker).

Server stability & persistence

The server is configured for continuous operation (intended 24/7). Backups and logging systems are in place to preserve world data; world resets are avoided unless technically necessary.

Server overview

This server aims to provide a near-vanilla Minecraft: Java Edition experience. Gameplay mechanics — progression, exploration, redstone, farming and other systems — behave as players expect from the official game. The server runs on Paper for improved performance and stability while preserving vanilla mechanics.

Server software: Paper (performance & stability for vanilla gameplay)

Client requirements
  • Connect using the official Mojang / Microsoft Minecraft: Java Edition client. Recommended version: 1.21.11.
  • Modified or unofficial clients that give unfair gameplay advantages (combat automation, x-ray, aim-assist, etc.) are not permitted.
  • Cosmetic or quality-of-life mods that do not affect game balance are generally acceptable.
  • Server-side anti-cheat systems are active to help ensure fair play.
Gameplay philosophy
  • Vanilla survival gameplay
  • Fair multiplayer experience
  • Minimal administrative interference
  • Long-term world stability

Plugins are used only for administration, moderation and technical features (permissions, rollback logging, performance monitoring). They are not intended to alter core survival mechanics.

Administration & moderation
  • Block logging and rollback tools
  • Anti-cheat monitoring
  • Permission management

Administrative intervention is kept minimal but will occur when necessary to address griefing, cheating or severe rule violations.

Bug reports & suggestions

Players are strongly encouraged to report server bugs, plugin issues and performance problems. Constructive suggestions are welcome and help guide future adjustments.

Suggested channels: in-game report form, Discord or issue tracker (insert links as applicable).

Server stability & persistence

The server is configured for continuous operation (intended 24/7). Backups and logging are used to preserve world data and protect player builds. World resets are avoided unless technically necessary.
